An entry for the [make.fun](https://make.fun/bounty/u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a) competition **Make the AI Judge Laugh: Office Jokes**.

## The entry

`main.py` writes a single original one-line joke about office life to
`/output/entry.txt`:

> The only thing our sprint delivers on time is the meeting about why the sprint is late.

## How it works

Run `python3 main.py`. It creates `/output` if needed and writes the joke
as UTF-8 text with no trailing newline — one line, 87 characters, inside the
competition's 1–199 character gate.
